
This template repository is uses as a basis for monorepo site packages, emphasizing; 

- Typescript & SASS 
- Efficient page level routing
- Efficient component detection and component instance code loading 
- Typescript classes for page and component code 

It also leverages a core engine portion named sse-core which can be updated for core functionality. 
It should contain nothing project-specific, and everything that can be shared and upgraded across projects. 

That code is accessible at ../sse-core for review, relative to this project folder.
